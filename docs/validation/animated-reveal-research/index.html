The direction for our pulls

Character movement

Breathing, a deliberate hand or weapon motion, stable facial features, and small follow-through. The pose carries the fighter’s identity.

Depth and surroundings

Separate near and far elements, changes in light, and atmosphere that can pass in front of the character. Movement should reveal prepared artwork beneath it.

A signature effect

An impact, trail, quake, spark or glow that belongs to that character. Todo’s reference is the quality target for active effects; Mahito’s is useful for quieter life and atmosphere.

The ensemble paintings can serve the memories / party-bonus direction. A fighter pull should show off its central character. The earlier rigged Mario was rejected for its execution; that feedback does not rule out a properly rigged character and a coherent animated scene.

Where Cubism helps

Open the real Cubism runtime test ↗ — Live2D’s official Haru sample, with an authored gesture, expressions, face-turn control and physics. This verifies model playback; it is separate from our character artwork.

Live2D’s showcase confirms Phantom Parade uses Cubism. Its editor gives us controlled local deformation, rotation, draw order, expressions, motion curves and secondary motion. The artwork and rig still need to be prepared well.

Character artwork → separated layers with hidden areas drawn → Cubism rig and animation → background/effect composition → moving pull proof → your feedback.
RequirementWhat it means for this project
Prepared artworkA layered PSD or an existing suitable rig. Cubism’s own workflow includes drawing parts that become exposed when other parts move.
Rigged movementUse rotation for rigid pieces and local deformation for soft movement. Large pose changes may require replacement drawings or additional poses.
Effects and sceneCompose these with the rig. Choosing Cubism alone does not create Todo’s impact effects, lighting or background.
PlaybackThe Web SDK fits our browser/Electron stack. For a fixed pull animation, Cubism can also export a video; the authored movement can be preserved without a live rig in the game.
Authoring hereThe supported editor runs on Windows and macOS, including Apple Silicon. This Linux workspace can run the Web SDK but does not have a supported Cubism Editor for making a new character rig.

The next visual proof should start from suitable character art and a real rig. The current catalogue cutouts and a whole-image sway are insufficient for this target. We are still checking character assets; no custom Nintendo Cubism rig is complete.
