# Owner-authored character storyboards — later tool

Requested 2026-10-15 America/Chicago. This is a future workflow, not an editor
implemented in the current Nightmare pass.

Goal: the owner can show the ideal character sequence in rough form; the agent
refines that intent into a feasible storyboard before producing sprites/rigging.
Do not require drawing skill or make the owner solve the asset pipeline first.

Candidate minimal workflow:

1. Choose a character and arrange rough frames / beats. Use simple silhouettes,
   hands, cloth, arrows, imported references or quick sketches.
2. Set duration, camera framing / slant / movement and written sound/music cues.
3. Play / step the rough board. Export a versioned data file plus frame sheet
   so the intended sequence can be handed back into this review workflow.
4. Before final production, assess each shot: existing sprites sufficient;
   extra pose needed; separated layers / hidden surfaces needed; or a camera
   move that needs 3D / substantial redrawing. Explain tradeoffs while preserving
   the visual intent. An ambitious rough board is not a promise that current
   sprites can perform it exactly.

Asset preference: owner permits AI-generated images for brief 1–2-second
transitional inserts, e.g. a missing back-view sprite. This is a narrow exception,
not blanket permission for generated backgrounds, persistent showcase art or
all character layers. Review exact character/version and consistency first.
No new generated assets are required for storyboard 02.

Keep the shared director separate from character choreography. Reuse current
single/ten, per-result cue, camera-before-identity, interruption and reduced-
motion contracts. Author one bespoke UR at a time; SSR-specific performances
may need their own boards. No production rarity/economy or roster migration is
part of this tool. Decide the editor's exact scope when the owner starts it.
