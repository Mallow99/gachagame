# First standalone splash (reference only)

The first Claude splash, before the splash kit. The owner liked the image, the blink and the look. They later rejected the warped robe and sway. Open `index.html` through `npm run web`. Art: the King Dedede render from Kirby's Return to Dream Land Deluxe and the Clash at Castle Dedede arena from Kirby Star Allies, both via WiKirby. Superseded by `demos/splash-kit/`.
